# The Law of Large Numbers

Probability Simulations with Python

A beginner-friendly Python project exploring fundamental concepts of probability and statistics through random simulations.

This project contains two simulations:

🪙 1. Coin Toss Simulation — Law of Large Numbers

The coin toss simulation demonstrates how experimental results behave as the number of trials increases.

The program simulates 10, 50, 100, 1,000, and 10,000 coin tosses, counts the number of Heads and Tails, calculates the percentage of Heads, and visualizes the results against the theoretical probability of 50%.

The simulation demonstrates how, with a sufficiently large number of trials, the observed proportion tends to move closer to the expected probability.

🎲 2. Dice Roll Simulation — Probability of Getting a 6

The dice simulation explores the probability of getting a 6 when rolling a fair six-sided die.

By repeatedly rolling the die and tracking how often 6 occurs, the project compares experimental probability with the theoretical probability of getting a 6.

For a fair die:

P(6) = 1/6 ≈ 16.67%

📌 Objective

The objective of this project is to understand probability concepts practically rather than relying only on mathematical formulas. By running thousands of random experiments, the project demonstrates how theoretical probabilities emerge from repeated observations.

This project is part of my journey toward combining Python programming, statistics, and quantitative/financial analysis.
